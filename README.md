# Alja Mikec

Osebna spletna stran Alje Mikec.

Spletna stran predstavlja področja:
- zdravstva,
- zobozdravstva,
- izobraževanja,
- raziskovanja,
- podjetništva,
- sodobnih digitalnih projektov.

## Vizija

Ustvarjanje sodobne osebne blagovne znamke, ki povezuje znanje, kakovost, raziskovanje in ustvarjalnost.


## Sodelovanje

Sodelovanje za:
- osebno predstavitev,
- strokovne članke,
- spletne tečaje,
- raziskovalno delo,
- digitalne produkte,
- prihodnje sodelovanje.
